# 💎 Jeweller Shop – Next.js Web Application

A modern and responsive **jewellery shop web application** built using **Next.js**, **TypeScript**, and **Tailwind CSS**.  
This project demonstrates clean UI design, scalable architecture, and real-world web development practices.

---

## 🚀 Tech Stack

- **Next.js** – React framework for production
- **TypeScript** – Type safety and maintainable code
- **Tailwind CSS** – Utility-first CSS framework for styling
- **Docker** – Containerized development environment
- **Jest** – Testing setup

---

## ✨ Features

- Responsive and modern UI  
- Jewellery product showcase with reusable components  
- Environment variable support  
- Docker & Docker Compose configuration  
- Clean and scalable project structure  
- Ready for production deployment
